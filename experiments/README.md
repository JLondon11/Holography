# Experiment provenance contract

Every benchmark must include: code commit, environment and package versions, CPU/GPU model, dataset identifier and license, exact input checksum, wavelength/pixel pitch/depth planes, optical target-field mapping, random seed, reconstruction algorithm, iteration budget, normalization, timing methodology, recorded arrays, metric script, and figure-generation command.

Never store protected patient data in a public repository. Deposit only deidentified shareable assets with documented authorization and provenance. Large assets should reside in governed external storage with checksums and retrieval instructions.
