# IEEE Transactions on Computational Imaging — working outline

**Working title:** Physics-Constrained Deep Unfolding for High-Fidelity Volumetric Computer-Generated Holography

> This is a hypothesis and research plan, not yet a demonstrated method.

1. Introduction — inverse problem, limitations, clearly falsifiable hypotheses.
2. Related work — latest volumetric CGH, learned inverse optics, neural operators, deep unfolding.
3. Forward model — discrete scalar diffraction, SI units, sampling, optical geometry.
4. Proposed approach — physically constrained network architecture and defined objective.
5. Baselines — AP/GS, SGD/Adam, L-BFGS, existing deep holography implementations.
6. Data protocol — MRI-to-optical target field assumptions, license, splits, provenance.
7. Experiments — spatial, axial and multiplane reconstruction, runtime and memory.
8. Robustness — noise, calibration, quantization and model mismatch.
9. Ablations — physical constraints, training components, filtering location, depth losses.
10. Physical validation — only if measured optical data exists; otherwise limit claims.
11. Discussion — limitations, generalization and reproducibility.
12. Conclusion.

**Acceptance gate:** Do not claim superiority or real-time operation without measured evidence.
