# CPU synthetic benchmark execution (2026-10-30)

Local execution: Python 3.13, PyTorch 2.10.0+cpu, size=32, epochs=2.
Exact command equivalent to `python experiments/benchmark_synthetic.py --size 32 --epochs 2`.
This is a **software smoke test only** with synthetic, physically propagated,
phase-only source masks; no patient data, no real optical measurement, no
comparison with published deep-holography baselines.

| Model | Initial validation MSE | Final validation MSE | Held-out test MSE |
| --- | ---: | ---: | ---: |
| PhaseCNN | 0.729208 | 0.687642 | 0.702052 |
| PhysicsUnrolledCGH (2 steps) | 0.741974 | 0.683909 | 0.705046 |

Results above are from a locally run equivalent implementation and need to be
re-run from the committed GitHub sources in CI to confirm identical results.

**Not a scientific comparison**: training lasts only two gradient steps; datasets
are generated by the same forward simulator used for reconstruction, and the
very small sample size gives no meaningful performance or generalization claim.

CPU timing has intentionally not been presented as meaningful model speed.
